# 짐콕 — 화면 안내

승객 앱과 역무원 앱을 한 프로토타입에 담았습니다. 왼쪽 목록에서 화면을 골라 봅니다.
설치·실행·API는 [`README.md`](./README.md)에 있습니다.

## 실행

```bash
npm install
npm start        # = vercel dev — UI + API (포트 3000)
```

`npm run dev`는 Vite만 띄우므로 `/api/*`가 404입니다. 화면만 볼 때 쓰세요.

## 화면

**승객 (P-00 ~ P-11)** — 승차권 예매 · 승차권 상세 · 서비스 안내 · 수하물 크기 인식 ·
등록 가능 판정 · 배정 대기 · 위치 배정 완료 · 내 수하물 위치 · QR 확인증 · 등록 관리 ·
문제 신고 · 특송 이용 안내

**역무원 (S-01 ~ S-08)** — 담당 열차 홈 · 열차 운영 요약 · AI 배정안 검토 ·
전체 적재 위치도 · 칸 상세 · 특송 작업 체크리스트 · 예외 처리 · 수동 재배정

## 시연 순서

1. **P-00** 열차를 조회해 예매합니다. 두 자리 조회번호(01, 02 …)를 받습니다.
2. **P-01** 승차권 상세에서 `수하물 등록하기`를 누릅니다.
3. **P-02** 사진을 첨부하면 바로 크기 인식으로 넘어갑니다.
4. **P-03** 인식된 가로·세로·높이를 확인하고, 다르면 그 자리에서 고칩니다.
5. **P-04** 등록 가능 판정 → `이 정보로 등록하기`
6. **P-05** `출발 30분 전 · AI 배정 시작`을 누르면 실제로 배정이 돕니다 (8초 안팎).
7. **역무원용**으로 전환해 S-04 위치도, S-06 특송 작업, S-07 예외 처리를 봅니다.

부피가 보관대 한 칸(105L)을 넘게 입력하면 P-04가 규격 초과 결과를 내고
P-11 특송 안내로 이어집니다.

## 먼저 볼 파일

| 파일 | 내용 |
|---|---|
| `app/page.tsx` | 화면 20개와 전환 로직 |
| `app/globals.css` | 모바일 프레임·사물함형 위치도 디자인 |
| `app.js` | React가 그린 화면에 실제 배정 결과를 채우는 레이어 |
| `lib/train.js` | 호차·보관대 정의 (7=A · 9=B · 12=C · 14=D) |

## 시연용으로 남겨둔 부분

- **QR 확인증** — 스캔이 연결돼 있지 않습니다. 코드 문자열로 만든 블록 아트입니다.
- **S-07 문제 등록** — 등록 결과를 서버에 보내지 않고 화면에서만 처리합니다.
- **승객이 첨부한 사진** — 브라우저 세션 안에서만 오갑니다. 서버에 저장하지 않습니다.

**크기 인식(P-03)과 배정(P-05·P-06·S-03·S-04·S-06)은 시연이 아니라 실제 Claude 호출 결과입니다.**
크기 인식은 4~6초 걸리고, 실패하거나 8초를 넘기면 24인치 표준 규격으로 넘어갑니다.
