# KTX 수하물 안심배정 앱 — 화면기획서 반영 수정본

서비스 안내, 등록 가능 판정, 수하물 등록 관리, 승객 도움 요청, AI 배정안 검토, 수동 재배정 등을 보강한 프로토타입입니다.

## 실행

```bash
npm install
npm run dev
```

## 먼저 볼 파일

- `app/page.tsx`: 승객용·역무원용 각 10개 화면과 화면 전환 로직
- `app/globals.css`: 모바일 프레임과 사물함형 적재 위치도 디자인
- `app/layout.tsx`: 페이지 제목과 공통 레이아웃

실제 사진 업로드와 QR 스캔은 연결되지 않은 화면 시연용 코드입니다.
